# 一块石头，怎样成为芯片的起点

9 分 58 秒中文科普，1080×1920、24fps、9:16。

本版重新撰写口播，以 28 个问题串起硅片制造的 8 个章节；84 个语义节拍、
335 条字幕，使用实际录音的词时间戳同步模型、局部标注和剪辑。
保留实物与图解配合，简化设备外壳，让晶格、生长、切割、抛光和检测的变化更清楚。

- MP4 是完整竖屏视频，`full-captions.srt` 是字幕。
- 工程 ZIP 包含源码、ComfyUI 工作流、口播缓存、词事件、必要照片、
  已生成实物片段和全部确定性模型片段。
- Git 仓库也能重建模型并运行缓存合成。完整入口见 `edit/ten-minute/README.md`。
- 原生代码画面为 1080×1920、24fps；三段新增 ComfyUI LTX 实物镜头为
  576×1024、24fps，短暂切入并在合成时放大。
- 模型权重与 ComfyUI 运行时需独立安装；参考片的画面、音轨、字幕不在工程内。
