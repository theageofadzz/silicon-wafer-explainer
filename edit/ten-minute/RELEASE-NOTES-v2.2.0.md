# v2.2.0 场景深化版

保留9分58秒中文旁白，将硅片制造的84个独立节拍深化为设备整体、作用部位、
内部剖面与结果镜头。288个机位按实际词组触发，306个讲解动作分别执行。
不以镜头数量代替科普语义检查。

- 补齐炉体承载、石墨电阻加热、气路、塔板、回流、沉积底座及提拉传动。
- 增加晶格纵深、缺陷邻域及外延腔体、基座、灯组和气体路径。
- 切片导轮、夹持进给、行星载具、抛光供液、清洗支承和检测光路各有独立结构。
- 精馏接触特写保留两类粒子的数量，展示从液相进入汽相及组成偏向；
  该比例仅作定性示意。洁净包装完成时盖板贴合盒壁。
- 修正局部引线被图层裁切后产生假终点的问题；目标不在可见区域时隐藏标注。
- 本轮实际运行ComfyUI LTX，重新生成石英、单晶棒和空白硅片三条摄影衍生镜头。
  复核后的片段最长分别2秒、1秒及1.25秒；后续回到对应机制，不循环补时。
- 拦截跨节拍重复的摄影或代码MP4，并核对模型源码、动作计划和镜头计划。
- 交付仍为1080×1920、24fps、9:16；摄影扩散素材原生576×1024，合成时放大。
