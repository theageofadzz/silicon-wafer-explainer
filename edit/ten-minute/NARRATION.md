# 旁白全文

01 / 这片镜面，难在哪里？
芯片开始时，没有那些复杂线路。它先是一片薄薄的硅，表面亮得像镜子。
常见的三百毫米硅片，直径接近餐盘，厚度却只有零点七七五毫米。
材料里的杂质、原子的排列和表面的高低，都要受到控制。它究竟怎么做出来？

01 / “很纯”究竟有多纯？
百分之九十九，就是平均每一百份里面，还混着一份别的东西。离芯片的要求还远。
电子级多晶硅能达到十个、甚至十一个九。每多一个九，剩余杂质再少十倍。
这是高纯原料的指标。后面有意加入的掺杂元素，要和失控的污染分开理解。

01 / 纯净，还要排得整齐
全是硅，也不等于合格。不同区域各排各的，取向不同的交界处，就会出现晶界。
单晶延续同一套晶格取向。像一张连续的网，而不是把几块不同方向的网拼接。
我们从石头中取出硅，提纯、长成单晶，再加工表面。先从石英开始。

02 / 石英里有硅，为什么不能直接用？
真实的石英，可以透明，也可以乳白。它的主要成分，是二氧化硅。
这里的硅与氧结合在一起。要得到单质硅，必须通过化学反应，把它们分开。
所以，沙子洗得再干净，也不能直接做芯片。洗掉泥土，并没有改变物质。

02 / 先把氧分离出来
石英和碳质还原剂进入电炉。电极送入能量，在高温区域，让还原反应发生。
合并看这组反应，氧主要随一氧化碳离开。液态硅汇集炉底，再从出料口放出。
工业硅的纯度通常约百分之九十八到九十九。硅炼出来了，但还远远不够纯。

03 / 固体难分，换一种形态
杂质筛不出来，怎么办？一条典型路线，是把硅转化成三氯氢硅等氯硅烷。
这改变了化学形态，不是简单熔化。目的是利用不同物质挥发性的差别。
经过汽化和冷凝，让不同组分走进不同的收集路径。提纯，由此有了新办法。

03 / 精馏塔，怎样把杂质分开？
塔内，蒸气向上，液体向下，不断接触。容易挥发的组分，更倾向进入蒸气。
重复这样的交换，组分逐渐富集，再分别收集。多个分离步骤，继续净化原料。
杂质种类不同，分离难度也不同。精馏不是万能滤网，需要整套工艺配合。

03 / 提纯之后，怎样变回硅？
进入西门子法反应器。细长的硅芯通电加热，成为硅沉积的起点。
高纯氯硅烷与氢气参加反应，硅沉积到硅芯表面，让棒体一层层长粗。
这是把硅重新沉积出来。气体循环和副产物处理，也是生产体系的重要部分。

03 / 高纯原料，为什么还要重熔？
取出硅棒，还要破碎、清理并洁净包装。工具带来的污染，也必须去掉。
原料很纯，却含有取向不同的晶粒。接下来，要打散原来的排列，再重新建立。
所以先熔化，再重新生长单晶。并不是让那些小晶粒，在固体里面自己转正。

04 / 一炉硅，怎样开始生长？
多晶硅装进石英坩埚。外侧有石墨支撑和热场，加热后，固体逐渐变成熔体。
气氛和热量分布也要控制。目标是保持稳定的条件，而不是温度越高越好。
加入极少量的硼或磷，可以调节电阻率。加入多少、分布怎样，都有要求。

04 / 谁来决定原子往哪儿排？
靠一小段籽晶。它已经是单晶，方向已知，给新来的硅原子一个排列参照。
籽晶接触熔硅，缓慢向上提拉。接触处凝固的新晶体，延续籽晶的取向。
晶体和坩埚的旋转，用来配合传热和物质输运，并不是把原子像螺丝一样拧上去。

04 / 为什么先拉出一根细颈？
热冲击可能引入位错。这是晶格中的线状缺陷，还可能在后续生长中延伸。
先拉出很细的颈部，让表面更近，使合适方向的位错在侧壁终止。这叫缩颈。
细颈关系到整根晶棒的品质。图中的红线表示位错，不是实际可见的裂缝。

04 / 细颈怎样长成粗晶棒？
调节温度和拉速，晶体直径逐渐增大，形成肩部。这一步叫放肩。
达到目标直径，进入等径生长。晶棒向上，固液界面继续补充新的晶体。
真实晶棒有金属般的光泽。它是慢慢长出来的，热场和拉速需要持续调整。

04 / 晶棒越来越重，怎样稳住？
晶棒越长越重，承重设计不能忽略。颈部结构或辅助机构，要配合安全生长。
熔体也不安静。温差和旋转带来的流动，会改变正在凝固的界面条件。
界面条件不稳定，均匀性就受影响。不仅要长得大，还要整根晶棒长得稳定。

04 / 磁场为什么能帮助长晶？
磁控直拉是一种办法。熔融硅能导电，磁场可以抑制某些流动，调节对流。
磁场不是把硅吸起来，而是影响流动与传热，帮助控制生长和杂质输运。
石英坩埚会引入氧。多少氧进入晶体、怎样分布，也受到熔体流动的影响。

04 / 需要控制的，不止是杂质总量
氧也不总是越少越好。配合热处理，可以参与吸杂等设计，关键是按用途控制。
掺杂还有分凝现象。元素在固体和液体中浓度未必相同，剩余熔体也会随生长改变。
所以，称准原料还不够。沿晶棒长度、沿半径的性质均匀性，都需要控制。

04 / 没有位错，就毫无缺陷了吗？
晶格可能少一个原子，形成空位；也可能多一个原子，挤进正常位置之间。
点缺陷在冷却时可能聚集。生长速度、温度梯度和后续热过程，都要配合控制。
单晶说的是取向，低缺陷说的是质量。不能把单晶，直接理解成绝对完美。

05 / 晶棒怎样变成圆片？
冷却后，切去不合要求的头尾，把外圆加工到指定尺寸。材料也在这里损耗。
确定晶向，制作定位缺口。看不见的晶格方向，给设备留下一个识别参照。
晶棒送向密集排列的细线。运动的线网，同时加工许多平行切面。

05 / 薄片，为什么不能一刀到位？
这里展示金刚线怎样逐步去除硅。为看清过程，线径和片间距都做了放大。
每道切口都会消耗材料，形成切缝损耗。算原料用量时，也要算上这些损失。
刚切下的片，还不够平、不够光。锯痕和受损层都在，必须继续加工。

05 / 为什么先照顾边缘？
硅很脆，尖边容易崩缺并产生颗粒。把边缘加工成圆滑轮廓，可以降低风险。
研磨让两面更平行，厚度接近目标。控制的是整片几何，不只把正面磨亮。
机械加工可能留下损伤。再用化学蚀刻移除一定材料，进一步去掉受损层。

05 / 镜面，是怎样抛出来的？
抛光垫和抛光液共同作用，表面发生化学作用，同时移走材料。这就是化学机械抛光。
放大看，突起逐渐被削低。压力、运动和供液条件，一起决定加工结果。
双面抛光后，还可以按要求精抛。镜面反光只是结果之一，平整需要实际测量。

05 / 看着平，和真的够平
平整有不同尺度。整片翘曲、局部平坦度和微观粗糙度，不能混成一个数字。
光刻需要清楚成像。有些地方高、有些地方低，就更难同时处在合适的焦点。
容许多少起伏，要看器件和产品规格。平整，是为了服务下一阶段的加工。

06 / 抛光结束，为什么还不能出厂？
表面仍可能有磨粒、有机残留和金属污染。清洗，要分别解决这些问题。
组合处理步骤后，用高纯水漂洗并干燥。去掉旧污染，也要避免新的残留。
夹具、空气和包装也要配合。每一次接触，都关系到清洁表面能否保住。

06 / 有些硅片，为什么再长一层？
部分产品还要外延：在受控条件下，让气相原料在硅片表面形成新的单晶层。
新层延续下面的晶格取向，同时按要求控制厚度和电阻率，提供所需材料特性。
这不是贴一层膜。抛光片和外延片，服务不同的使用要求，外延也并非必经步骤。

07 / 怎样证明每片都合格？
发亮不等于合格。颗粒、缺陷、厚度、平整度和电学性质，各有测量方法。
用光扫描表面，可以关注异常散射。探头与光点关联运动，覆盖检查区域。
几何测量回答厚不厚、平不平、有没有翘曲。和颗粒检查，是不同的任务。

07 / 离开工厂，洁净还要继续
身份记录要能追溯到晶棒和批次。出现问题时，才能回查原料和加工环节。
专用运输盒保护硅片，减少颗粒和接触污染，把合格材料送往后续工厂。
这里仍是芯片的材料起点。光刻、刻蚀、沉积和互连，属于接下来的器件制造。

07 / 难的不只是做出一片
做出样品，和持续量产，是两件事。客户需要每批都稳定，还要适配自己的工艺。
信越、胜高、环球晶圆、世创和爱思开矽特隆，都是重要的硅片供应商。国内也在发展。
不能只数厂房和规划产能。量产质量、客户验证与稳定交付，共同决定生产能力。

08 / 从石头，到芯片的起点
石英经还原得到硅，再转化、分离和沉积，一步步降低不需要的杂质。
借助籽晶建立取向，控制生长与缺陷；再切磨抛、清洗和检测，得到合格硅片。
一片镜面，背后是一整条精密制造链。我们熟悉的计算世界，就从这样的材料上开始搭建。
